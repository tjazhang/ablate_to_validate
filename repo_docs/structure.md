## Vendored methods

- `methods/llava`
- `methods/qwen`

These are copied code snapshots, not symlinks.

## Overlay methods

- `overlays/mirage`
- `overlays/mull`
- `overlays/covt`

Each overlay method contains:

- `source.lock`: pinned upstream repo metadata
- `patches/`: optional `*.patch` files applied after checkout
- `overrides/`: exact files copied into the external checkout

## Materialized upstream code

- `external/<method>/upstream`

These are generated by `tools/bootstrap_overlay.py`.
